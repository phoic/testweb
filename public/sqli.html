‘인증 우회 관찰’은 별도의 매개변수화 조회에서 정확한 계정이 일치하지 않는데 취약 경로가 인증에 성공한 경우에만 표시합니다. 이 확인은 두 경로의 인증 결과를 변경하지 않습니다.

05 원리 설명

아래는 설명이며 DB 내부 관측 로그가 아닙니다.

문자열 연결

입력값을 따옴표 사이에 직접 넣으면 입력의 작은따옴표가 문자열을 닫고, 이후 내용이 SQL 조건식의 일부가 될 수 있습니다.

논리식과 주석

제공된 예시의 OR '1'='1'은 참인 조건을 추가하고, --는 뒤의 비밀번호 조건을 주석으로 만듭니다. 실제 결과는 위의 실행 자료에서 확인하세요.

매개변수 바인딩

고정 SQL의 ?에 값을 별도로 전달합니다. 값 안의 따옴표, 논리식, 주석 문자가 SQL 구조를 변경하지 않습니다. 템플릿과 바인딩 값은 실행 자료에서도 분리해 표시합니다.
