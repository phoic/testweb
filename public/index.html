GUIDE 실습 진행 방법

1. 같은 입력을 두 버전에 넣어보기

각 Lab에는 Vulnerable / Secure 두 개의 패널이 나란히 있습니다. 동일한 테스트 입력을 두 쪽에 각각 넣고 결과를 비교하세요.

2. 처리 흐름과 실제 쿼리 확인하기

입력 → 서버 → DB/브라우저로 이어지는 처리 단계가 화면에 표시되고, 실제로 실행된 SQL 쿼리 또는 렌더링 방식이 코드 형태로 함께 보여집니다.

3. 왜 그런 결과가 나왔는지 읽어보기

각 Lab 하단의 보안 분석 패널에서 취약점이 발생하는 이유와 방어 코드가 그것을 어떻게 막는지 설명을 확인할 수 있습니다.
